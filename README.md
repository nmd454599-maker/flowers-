# أزهارنا Pro — النسخة البرمجية 0.3

مشروع Flutter عربي RTL لمتجر متعدد البائعين للزهور والهدايا، مستوحى في تجربة الاستخدام من تطبيقات التجارة الحديثة مع هوية وكود مستقلين.

## الموجود الآن
- شاشة ترحيب وتسجيل دخول تجريبي
- نوعان من الحسابات: عميل / متجر
- واجهة عربية RTL
- الصفحة الرئيسية
- متاجر مقترحة
- صفحة متجر
- تصنيفات وفلترة منتجات
- صفحة تفاصيل المنتج
- مفضلة
- سلة كاملة وتغيير الكميات
- صفحة إتمام الطلب
- إنشاء الطلبات محليًا
- متابعة الطلبات
- حساب العميل
- لوحة المتجر
- إدارة حالة الطلب من حساب المتجر
- قائمة منتجات المتجر

## المرحلة التالية للنسخة التجارية
- Firebase أو Backend API حقيقي
- OTP للهاتف
- قاعدة بيانات للمستخدمين والمتاجر والمنتجات والطلبات
- رفع صور المنتجات
- Google Maps / تحديد الموقع والعناوين
- Push Notifications
- Chat حقيقي
- بوابة دفع عراقية/بطاقات
- لوحة إدارة Web
- صلاحيات واعتماد المتاجر
- كوبونات وعروض
- تتبع السائق والتوصيل

## التشغيل
بعد تثبيت Flutter:

```bash
flutter pub get
flutter run
```

> البيئة الحالية التي تم إنشاء المشروع فيها لا تحتوي Flutter SDK، لذلك تم تجهيز المصدر وهيكل المشروع، لكن يلزم تشغيله على جهاز يحتوي Flutter/Android Studio أو Xcode لإجراء build فعلي.

## إضافات النسخة 0.3
- تسجيل دخول عبر تدفق OTP تجريبي (الرمز 1234)
- اختيار نوع الحساب قبل الدخول
- شاشة عناوين وإضافة عنوان جديد
- محادثة عميل/متجر محلية قابلة للربط بالسيرفر
- مركز إشعارات مع عداد غير مقروء
- روابط فعلية من صفحة الحساب للشاشات الجديدة
- BackendContract لتحديد نقاط الربط المطلوبة مع Firebase أو REST API
