# حماية الجلسات وبيئات التشغيل والطلبات

## المنفذ

- كل عملية حالة تحمل رمزاً مرتبطاً بعمر الجلسة. تُفحص صلاحيته بعد انتظار المستودع وقبل نشر النتائج.
- تسجيل الخروج يمسح البيانات المحلية فوراً، يمنع بدء عمليات جديدة، ثم ينتظر عمليات التوثيق الجارية قبل إنهاء جلسة المستودع. لا يعيد رد قديم تعبئة بيانات المستخدم التالي.
- تدمير الحالة يبطل العمليات ويمنع إشعار واجهات متلفة.
- عداد عمليات مستقل عن نتيجة الطلب يمنع إخفاء التحميل عند انتهاء إحدى عمليتين متزامنتين.
- تحميل الكتالوج يحمل رقم طلب، فلا تستبدل نتائج مدينة سابقة نتائج المدينة الحالية.
- دخول الإدارة الخارجي يستخدم نفس دورة حماية الجلسة مع الحفاظ على claims والتحقق الثنائي.

## البيئات

- `debug` افتراضياً: APP_ENV=local وUSE_FIREBASE=false، مع تعريف SQLite كمسار تجربة.
- `release` افتراضياً: APP_ENV=production وUSE_FIREBASE=true.
- التطبيق يرفض تشغيل release ببيئة local، أو تشغيل staging/production مع مستودع محلي. الفحص runtime فعلي وليس assert قابل للإزالة.
- لتجربة Firebase: `flutter run --dart-define=APP_ENV=staging --dart-define=USE_FIREBASE=true`.
- للإنتاج: `flutter build appbundle --release --dart-define=APP_ENV=production --dart-define=USE_FIREBASE=true`.

اسم staging لا يغير مشروع Firebase تلقائياً: يجب توفير إعداد Firebase لمشروع اختبار مستقل قبل اعتباره معزولاً عن الإنتاج. إعداد المشروع الحالي يبقى كما هو.

## الطلبات

المسار المباشر المسموح: newOrder → preparing → delivering → delivered. لا رجوع ولا قفز ولا إعادة فتح طلب نهائي. تتحقق قواعد Firestore كذلك من وقت تحديث الخادم، وتحتفظ بصلاحيات المندوب وحصره بطلباته.

تعكس قوائم المتجر والإدارة هذه السياسة وتعرض فشل التحديث للمستخدم. الإلغاء عبر تعديل status مباشرة محظور؛ يحتاج مسار خادم مستقل يعالج المخزون والدفع والاسترداد. هذا المسار غير منفذ ضمن هذه المرحلة.

## التحقق وحالة النشر

اختبارات Flutter تغطي تأخر نتائج الإدارة والدخول، تسجيل الخروج أثناء العمليات، التخلص من الحالة، التحميل المتزامن، المدينة الأحدث، إعداد الإنتاج والانتقالات. اختبارات Firebase Emulator تغطي انتقالات المتجر والإدارة إضافة إلى صلاحيات المندوب والمحادثات وحساب الطلب والمخزون.

اجتاز المحاكي 17 اختباراً. قواعد firestore.rules جاهزة محلياً؛ رفضت المراجعة التلقائية نشرها إلى azharna-production لغياب موافقة صريحة على هذا النشر. لم تتغير قواعد الإنتاج حتى الحصول على الموافقة وإثبات نجاح النشر.
