# مقارنة الخطوط على التصميم الأصلي

اعتمد المستخدم الخيار D — Noto Naskh Arabic. أصبح الخط الافتراضي عند تشغيل التطبيق، وأُخفي شريط المقارنة من واجهة العميل المعتادة. المقارنة المؤقتة متاحة فقط من نقطة المعاينة أدناه.

تمت إعادة HomeScreen وFloatingNavigation الأصليين كواجهة العميل الافتراضية بناءً على طلب الحفاظ على التصميم. معاينة الاتجاهات القديمة ما زالت متاحة عبر main_design_preview.dart فقط.

الخيارات: A تجوال (الخط السابق)، B القاهرة Cairo، C IBM Plex Sans Arabic، D Noto Naskh Arabic. الاختيار مؤقت أثناء الجلسة حتى اعتماد المستخدم للخط، ولا يغيّر الألوان أو الأحجام المحددة أو ترتيب الأقسام.

```sh
flutter run -d chrome -t lib/main_font_preview.dart
```

اختر الخط من الشريط أعلى الشاشة (قابل للسحب أفقيًا). الصور في artifacts/font-previews. الفاتح والداكن متاحان من زر المظهر. تغيّر مقاييس الحروف قد يغيّر التفاف النص؛ هذه نتيجة الخط نفسه.

تم تعديل app_theme.dart وmain.dart لربط اختيار الخط بإعادة بناء ثيم التطبيق، وcustomer_shell.dart لإعادة التصميم الأصلي وعرض خيارات الخط. أضيف font_options.dart وmain_font_preview.dart واختبار font_preview_test.dart. أضيف الخطان الجديدان إلى pubspec.yaml مع ملفاتهما وتراخيصهما محليًا.

المصادر: https://github.com/google/fonts/tree/main/ofl/cairo وhttps://github.com/google/fonts/tree/main/ofl/notonaskharabic. تراخيص OFL محفوظة بجانب ملفات الخطوط.

نجح اختبار عرض الخطوط الأربعة عند 430×1000، والتبديل والاحتفاظ بالسلة وتصدير الصور. لم يتغير منطق البيانات أو الخدمات.
