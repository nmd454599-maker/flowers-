# التحقق قبل إصدار المتجر

لا تصنّف الحزمة نهائية حتى اجتياز جميع البنود وتسجيل الجهاز والتاريخ والنتيجة.

| الرحلة | المطلوب |
|---|---|
| عميل جديد | هاتف حقيقي، OTP خاطئ ومنتهي وإعادة إرسال، إنشاء ملف، إغلاق وإعادة فتح |
| إدارة | بريد موثق، TOTP تسجيل وإعادة دخول، رفض جلسة بلا MFA، تعطيل المستخدم واسترداد الوصول |
| متجر | اعتماد متجر، رفض متجر موقوف، رفع صورة، منع الوصول لمتجر آخر |
| طلب | حساب السعر على الخادم، نفاد المخزون، تغير السعر، انقطاع الاتصال وإعادة المحاولة بلا تكرار |
| دفع | مزود sandbox ثم عملية حقيقية محدودة، توقيع Webhook خاطئ، تكرار الحدث، اختلاف العملة/المبلغ، استرداد |
| محادثة | العميل والمتجر والدعم على أجهزة مختلفة، رفض غريب، انقطاع الشبكة، تبديل الحساب |
| مندوب | حساب معتمد، إسناد الطلب، منع الوصول لغير المسند، انتقال تجهيز/توصيل/تسليم |
| خصوصية | روابط عامة، حذف من داخل التطبيق وخارجه، إزالة بيانات فعلية، مراجعة Data Safety |
| تشغيل | نسخة احتياطية مكتملة واستعادة تجريبية، خطأ تجريبي يصل إلى قناة التنبيه |
| Android | توقيع upload وPlay App Signing، بصمات Firebase، App Check على Internal testing، فحص AAB |

الاختبارات الآلية لا تعادل اختبار OTP وTOTP وPlay Integrity والدفع على أجهزة فعلية.
