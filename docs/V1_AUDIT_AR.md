# مراجعة أزهارنا وخطة النسخة الأولى

تاريخ: 2026-09-08. نطاق المراجعة: المصدر المحلي والوثائق الموجودة. لم يُفحص حساب Firebase السحابي أو Google Play أو هاتف فعلي في هذه الجولة. المجلد الحالي ليس مستودع Git وفق نتيجة git status؛ لم يُنشأ تاريخ تغييرات بديل.

## نتيجة المراجعة

المشروع متجر زهور وهدايا متعدد البائعين قائم بالفعل. يحتوي Flutter للعميل والمتجر والإدارة، ومشروع courier_app للمندوب، وFirebase Repository ووظائف خادم وقواعد Firestore وStorage. SQLite مسار تجربة محلية، وبعض عملياته ترث تنفيذًا تجريبيًا؛ وجود شاشة لا يثبت اكتمال ربطها بالإنتاج.

README الأساسي يصف مرحلة أقدم من الكود؛ تقريران أحدث هما [حالة التنفيذ](IMPLEMENTATION_STATUS_AR.md) و[تحديث 7 سبتمبر](READINESS_UPDATE_2026_09_07_AR.md). ما ورد فيهما عن السحابة والاختبارات السابقة سجل تاريخي يحتاج إعادة تحقق عند النشر.

## ترتيب العمل التالي

1. تنفيذ تصميم السلة متعددة المحلات مع طلب وتوصيل مستقلين لكل محل، وإعداد رسوم يحددها المحل وتُحسب وتُثبت من الخادم عند إنشاء الطلب.
2. تنفيذ فجوات الطلب والرسوم والتحصيل والخصوصية مع اختبارات موجهة.
3. مراجعة الواجهات وفق الرحلات ثم استكمال التكاملات واختبارات الأجهزة.
4. التحقق من السحابة وخطة النشر وتشغيل المراقبة والنسخ الاحتياطية.
5. قبول Android داخليًا، ثم الإطلاق والمتابعة، ثم تجهيز iPhone.
