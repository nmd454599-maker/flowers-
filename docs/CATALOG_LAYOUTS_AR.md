# مقارنة عرض المنتجات في التصنيفات

اعتمد المستخدم التصميم 03. تعرض صفحة التصنيفات CatalogLayout.dense افتراضيًا حتى عند تمرير null من غلاف العميل. تظهر ثلاثة أعمدة على عرض الهاتف 360 عند الحجم المعتاد للنص، ويتكيف عدد الأعمدة مع العرض وتكبير النص. هذه البدائل تستخدم نفس قائمة المنتجات الناتجة من البحث والتصنيف والتصفية والترتيب، ونفس إجراءات AppState للمفضلة والسلة وشاشة تفاصيل المنتج.

01 عمودان بصور واضحة؛ 02 عمودان مختصران؛ 03 ثلاثة أعمدة على عرض الهاتف 360؛ 04 قائمة بصور جانبية؛ 05 قائمة مدمجة؛ 06 رفوف أفقية مجمعة حسب التصنيف. عدد أعمدة الشبكات يتكيف مع العرض وتكبير النص.

```sh
flutter run -d chrome -t lib/main_catalog_preview.dart
```

بدّل من القائمة أعلى المعاينة. بيانات DemoRepository مستقلة عن حسابات المستخدم. الصور في artifacts/catalog-previews، واللوحة المجمعة all-six.png. اختبارات catalog_preview_test.dart تغطي العرض عند 360×900 وإجراءات المفضلة والسلة وتفاصيل المنتج لجميع الخيارات.

الملفات: widgets/catalog_layout.dart؛ main_catalog_preview.dart؛ ربط اختياري في categories_screen.dart وcustomer_shell.dart. لا تغيير لـAPIs أو قاعدة البيانات أو الألوان أو الخط أو أحجام الأيقونات المعتمدة.
