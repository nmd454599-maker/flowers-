#حاول hvd] مقارنة تصاميم أزهارنا

## المراجعة قبل التنفيذ

راجعت بنية Flutter، نقطة التشغيل والثيم والتوكنات، تجميع الرئيسية ومكوناتها، مسارات العميل، عقد المستودع ووحدات الحالة، وتوثيق واجهات المتجر والإدارة والمندوب. التطبيق يستخدم AppState مشتركًا مع مستودعات Demo / SQLite / Firebase. التنقل الحالي عبر MaterialPageRoute، وتبويبات العميل تُحمّل عند زيارتها وتحتفظ بحالتها داخل AnimatedTabBody. هذه مراجعة لتحديد حدود تعديل الواجهة، وليست تدقيقًا أمنيًا أو اختبارًا للخدمات المنشورة.

الرئيسية الأصلية `home_screen.dart` ومكوناتها محفوظة. واجهة العميل تستخدم الآن `DesignHome`، مع استمرار البحث والتصنيفات والمناسبات والبنرات والمنتجات والمتاجر والعناوين والإشعارات والسلة والمفضلة والخريطة والمحادثات والإعلانات والطلبات والحساب والتتبع. لم تتغير عقود API أو المستودعات أو قاعدة البيانات أو المصادقة أو حساب الأسعار.

## التشغيل والمقارنة

للمعاينة المباشرة بكتالوج تجريبي دون تسجيل دخول:

```sh
flutter pub get
flutter run -d chrome -t lib/main_design_preview.dart
```

ويمكن استخدام جهاز Android بدل `chrome`. نقطة المعاينة مستقلة ولا تهيئ Firebase أو SQLite. لتجربة التدفق المعتاد استخدم `flutter run` ثم ادخل إلى واجهة العميل.

أعلى واجهة العميل يوجد شريط Design A / Design B / Design C / Design D؛ اسحبه أفقيًا على الشاشة الضيقة لإظهار بقية الخيارات. زر الشمس/القمر بجانبه يتيح الفاتح والداكن ومظهر الجهاز. الاختيار الافتراضي A، واختيار التصميم يظل للجلسة الحالية ولا يُحفظ بعد إعادة التشغيل. حالة السلة والمفضلة والتبويبات لا تُعاد تهيئتها عند التبديل.

| الاتجاه | التكوين والبطاقات | البحث والأقسام | التنقل والخط |
|---|---|---|---|
| Design A — حديقة الورد | وردي، حواف 28، مسافات 20، شبكة منتجات وصور أقسام دائرية | عنوان ثم بحث كبسولي ثم أقسام وبنرات صور | شريط عائم مستدير، Tajawal عريض |
| Design B — بوتيك الهدايا | أخضر، حواف 8، مسافات 28، بطاقات منتجات كبيرة قابلة للسحب، بنرات غير متساوية العرض على الشاشات الواسعة | عنوان مركزي تحريري، بنرات قبل البحث المحدد بإطار، أقسام صور عريضة | شريط متصل هادئ ومؤشر صغير الزوايا، IBM Plex Arabic |
| Design C — لحظات ملوّنة | بنفسجي، حواف 20، بطاقات ملونة بارتفاع بصري خفيف | البحث أولًا، شبكة أقسام 2 أو 4 أعمدة، بنرات متجاورة عند توفر العرض | شريط عائم يعرض اسم الوجهة المختارة، Tajawal |
| Design D — اختيارك اليومي | بني دافئ، حواف 12، مسافات 12، منتجات بقائمة أفقية الصورة والتفاصيل | بحث مدمج، أقسام ومناسبات كشرائح، بنرات أفقية صغيرة | شريط متصل بارتفاع 72، IBM Plex Arabic |

كل اتجاه يستخدم ColorScheme.fromSeed للفـاتح والداكن وMaterial 3، ويحتفظ بالأقسام الثمانية والمناسبات الخمس. يستخدم الخطين الموجودين أصلًا في assets دون تحميل خطوط من الإنترنت. الصور الحالية مستخدمة، ولا تُعرض خصومات أو نسب عروض مختلقة.

## الملفات

- `lib/core/home_design.dart`: تعريف الاتجاهات وColorScheme والثيم والخطوط والحواف.
- `lib/screens/customer/home/design_home.dart`: التكوينات الأربعة وإجراءات المنتجات ومسارات الرئيسية الحالية.
- `lib/screens/customer/home/design_navigation.dart`: أنماط NavigationBar الأربعة.
- `lib/screens/customer/customer_shell.dart`: محدد المقارنة وربط الرئيسية والثيم مع التبويبات الحالية.
- `lib/main_design_preview.dart`: تشغيل المقارنة ببيانات DemoRepository.
- `lib/widgets/product_card.dart`: جعل وصف التوصيل مرنًا لمنع تجاوز العرض مع الخط الجديد في نتائج البحث.
- `pubspec.yaml`: تسجيل خط IBM Plex Arabic الموجود محليًا.
- `test/home_designs_test.dart`: مصفوفة المقاسات/الثيم، حفظ الحالة وفتح البحث، وتصدير الصور.
- `artifacts/home-designs/design-a.png` إلى `design-d.png`: معاينات مولدة من Flutter.

## التحقق

اختبار العرض يغطي 320 و390 و768 و1200 بكسل لكل اتجاه في الفاتح والداكن، مع التمرير إلى محتوى أسفل الشاشة. اختبار المقارنة يتحقق من استمرار السلة والمفضلة وفتح البحث. توليد الصور يتم داخل اختبار Flutter وليس من نموذج تصميم منفصل.

```sh
flutter test --no-pub test/home_designs_test.dart
```

الثيم البديل محصور داخل واجهة العميل؛ باقي نقاط الدخول تحتفظ بثيم التطبيق الأصلي. محدد المقارنة أداة معاينة يمكن إخفاؤها لاحقًا بعد اعتماد اتجاه. لم يُنفّذ نشر أو اختبار دفع/طلب على خدمة حية.

### نتائج التنفيذ

- نجح الفحص الساكن للملفات السبعة المعدلة/الجديدة دون ملاحظات. الفحص الشامل أظهر أيضًا ملاحظة `prefer_const_constructors` في `app_theme.dart:122` الذي لم يُعدّل.
- نجحت الاختبارات الثلاثة في `home_designs_test.dart`، بما فيها 32 تركيبة تصميم/مقاس/سطوع.
- الحزمة الشاملة وصلت إلى 68 نجاحًا و3 إخفاقات قبل الإصلاح الأخير: اختبار واجهة العميل كان يرى زري مظهر عند فتح الحساب؛ عولج التكرار بإبقاء زر الحساب الأصلي. اختبارات الرئيسية الأصلية `redesigned screens fit phone and tablet in both themes` و`reference design fits narrow phones and categories filter the catalog` أظهرت تجاوزات تخطيط في المكونات القديمة مثل `home_campaigns.dart`. لم تُستبدل الرئيسية القديمة ولم تُغيّر هذه الاختبارات لإخفاء الإخفاقات؛ لذلك لا تُعد الحزمة الشاملة ناجحة بالكامل.
- رُفعت اختصارات الخريطة والمحادثات والإعلانات إلى أعلى الرئيسية لسهولة الوصول.
- إعادة اختبار `existing customer shell opens announcements and account` اجتازت جزء العميل بعد الإصلاح، ثم فشلت في جزء `StoreShell` بتجاوز عرض 29 بكسل؛ واجهة المتجر لم تُعدّل. تبقى ثلاثة اختبارات في الحزمة بحاجة معالجة تخطيط الواجهات القديمة.
