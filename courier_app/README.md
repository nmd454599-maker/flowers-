# أزهارنا للمندوب

تطبيق Flutter مستقل بحزمة Android `com.azharna.azharna_courier`، مسجّل في مشروع `azharna-production`.

يدخل المندوب برقم الهاتف ورمز Firebase. يتطلب الوصول مطالبة `role=courier` موقعة وملف مستخدم نشط بالدور نفسه. تظهر فقط الطلبات التي تحمل `assignedCourierId` المطابق للحساب، وتسمح القواعد بالانتقال من `preparing` إلى `delivering` ثم `delivered`.

يُسند المسؤول الطلب من زر المندوب بجانب الطلب في لوحة الإدارة بعد دخوله بتحقق ثنائي. يمكن اعتماد حساب المندوب الموجود بواسطة أداة `functions/scripts/grant-courier.js` من بيئة إدارية موثوقة؛ لا تضف الصلاحيات من التطبيق.

```powershell
flutter.bat pub get
flutter.bat analyze
flutter.bat test
flutter.bat run
```

ملف Firebase موجود في `android/app/google-services.json`. مفاتيح التوقيع خاصة ومحلية؛ الإعداد الحالي يشير إلى مفتاح الرفع الموجود في المشروع الأب. عند نقل المشروع إلى جهاز آخر، وفر مفتاح الرفع وإعداداته بشكل آمن.

يلزم نشر قواعد المشروع الأب وتفعيل App Check وتسجيل حساب مندوب حقيقي قبل اختبار الطلبات فعليًا. هذه النسخة لا تتضمن تتبع الموقع الحي أو الملاحة أو إشعارات الإسناد، ولا تُعد إصدار متجر نهائيًا.
